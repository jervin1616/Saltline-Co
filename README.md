# Saltline Co.

**Wear the Coast.**

E-commerce spec portfolio project by [Rising Tide Digital LLC](https://jervin1616.github.io/RisingTideDigital/).

Demonstrates a coastal lifestyle brand store with:
- Functional React cart (add, remove, quantity, subtotal)
- Product filtering by category + sort
- Product detail pages with size selection
- Slide-in cart drawer UI
- React Router v6 client-side routing
- GitHub Pages SPA routing via 404.html redirect

## Tech Stack

- React 18 + Vite
- Tailwind CSS v3
- React Router v6
- React Context API + useReducer
- Google Fonts: Syne + DM Sans
- Deployed via gh-pages

[https://jervin1616.github.io/Saltline-Co/](https://jervin1616.github.io/Saltline-Co/)

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build     # builds to /dist
npm run deploy    # pushes dist to gh-pages branch
```

## Contact Form

To enable the contact form, replace `REPLACE_WITH_WEB3FORMS_KEY` in `src/pages/Contact.jsx` with your real [Web3Forms](https://web3forms.com/) access key, then rebuild and redeploy.
